## Como registrar o progresso

1. Ao fim de cada sprint, copie o modelo de Sprint Report para `docs/gestao/sprints/sprint-NN.md` e preencha.
2. Depois de cada reunião, copie o modelo de ata para `docs/gestao/reunioes/AAAA-MM-DD.md`.
3. Cada integrante faz commit das próprias contribuições, para que o histórico mostre o trabalho de toda a equipe.
